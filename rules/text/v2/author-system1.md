# system1-agents 作者层（候选）

版本：`text-v2.0.0`。层标识：`author.system1`。来源及取舍见 [author-reference](../author-reference.md)。本文件是本项目重写的规则，不是原 skill 副本；由 text-v2.0.0 固定规则解析器按显式项目选项接入。

## 适用与优先级

只在本次资料明确以 system1-agents 为对象、并要求参考用户 s1a-launch-kit／作者稿时应用。不能仅凭 LinkedIn、AI agents、System 1 或技术产品关键词给别的产品套用本层。作者身份由本次选项决定；选择第三方介绍时不冒充原作者。

与通用、LinkedIn普通动态和语言层合并成每个平台×语言的一套规则。优先级以 [固定映射](../option-mapping.md) 为准：事实保真和平台硬限制先满足；当前用户指示确定范围和目的；本层偏好不豁免核查。中文与英文从同一母稿和平台稿衍生，观点、条件、产品边界一致，不逐字硬译。每份初稿只审核一次再统一修订；本层的检查是同一次审核的一部分，不新增多轮流程。

## 写作规则

- **SYS-A01｜固定标题与中文候选。** 英文沿用原件锁定标题时必须完整逐字保留：`Give your agents a Jev-like System 1 decision model. Start from a prebuilt agent or build your own.` 本轮 system1-agents launch feed 采用此标题，不因去 AI 味、长度优化或 generic hook 改写。中文可写自然译题，但审核记录明确“中文译题待作者确认”，不把该状态塞入公开正文；不能声称原作者已批准中文。锁定标题不要推广为其他产品模板。若本次用户另有标题指示，以本次明确指示为准并记录。
- **SYS-A02｜模型、代理与示例。** 正文使用 `System 1 decision model`（中文解释为“System 1 决策模型”）、`System 1 agent`（“System 1 智能体”）、`LLM`（首次解释为 large language model／大语言模型）。Jev、Laya、Cua-S1 Nano 保持拼写。模型与 agent 不互换；正文不以 chat model、S1A agent、decider、classifier 替代上述类别。用 such as／例如列举模型，不写 all three，不由开放列举暗示支持任何模型。内部审核可原样引用异名来定位差异。
- **SYS-A03｜作者的信息主线。** 围绕本次目的选择一条用途，让读者理解有限选项决策与 LLM 职责的关系；调用／构建路径按理解需要取舍。以上不是固定段序，固定标题之后可以接本次读者最需要的解释。普通动态不照搬长文标题清单；保留具体信息，避免把模型分工删成只有“更快更便宜”的宣传。不要求每篇齐列所有场景、技能和收益。
- **SYS-A04｜适度技术细节。** 面向产品介绍时不堆 JSON、代码参数、价格、延迟、探测次数、库名或基准行清单；不加入 agent-framework 名称和许可证宣传。必要的适用条件、宿主范围、推理限制必须保留。内部证据元数据仍记录许可、版本与技术条件；公开措辞偏好不能豁免核查。
- **SYS-A05｜自足的普通动态。** Feed 正文独立可理解，不要求先有 Pulse 长文。仅使用本次已核对的真实资料链接；不生成占位文章 URL、不暗示新长文已经发表。不将旧“文章先发、动态后发、仓库链接放首评”流程或算法经验当成本轮要求。链接与说明服务当前读者，CTA未指定就不强制加问题、关注、试用或购买句。
- **SYS-A06｜保留声音而不固化营销。** 作者明确锁定的修辞，不因 AI 风格词表或评分自动删除；但涉及社区反响、日期、先后、性能、读者收益等仍是事实主张，须走事实门槛。旧口号与夸张叙事不自动成为新稿必填句。若本次用户明确要求保留某句而证据不足，保持来源原文和问题记录，给可证实的候选表达及未解决项，不把缺证据的句子伪装成已验证事实，不暗改原件。
- **SYS-A07｜标签与视角。** 本项目 launch feed 若沿用原件标签，使用其 LinkedIn 集合 `#Jev #SystemOneModels #AIAgents #OpenSource`；本次用户明确选择不加或改标签时从其指示。它是作者选择，不是传播保证或通用强制模板。正文只有来源明确支持的亲历、归属或承诺才用“我／我们”；不得为增强可信度捏造使用经历、用户反馈或测量。

## 事实门槛

- **SYS-F01｜每个主张有类型和来源。** 写前实读本次资料，至少区分产品功能、作者观点、历史事件、基准结论、当前计划、本次实际操作。对可变主张记录文件/URL、commit或版本、核查日期以及文档陈述/本次实测的证据类型。参考稿提供语气与结构，不能充当所有事实的唯一凭据。正文、主张映射和审核发现只在 tmp。
- **SYS-F02｜限定选择分工。** 只把适合从可枚举选项中选择的步骤交给 System 1 decision model。明确 LLM 仍承担规划、计算、推理、生成文本及资料支持的其他职责。不要说所有代理每一步都必须走 LLM、System 1 替代 LLM、所有步骤都适配、无需 LLM 或自动智能回退；若来源有更窄边界，采用更窄边界。
- **SYS-F03｜调用和构建分开核对。** 核对 caller 与 builder 的宿主和前提，不把共用主语下的两个动词扩为每个宿主都支持两条路径。2026-09-24固定 commit 的具体文档支持 caller 使用 Claude Code／Codex等宿主，builder 描述为 Claude Code checkout 中运行；新稿不得声称 Codex builder 已验证。此处是当日证据，后续资料变化需重新读，不永久冻结产品能力。模型支持列表不等于各模型性能均获验证。
- **SYS-F04｜旧性能不是新事实。** 原件的6×／25×、同分、每步延迟、降低读者成本和提高速度不能直接继承。引用任何比较须有具体任务、模型及比较基线、版本、样本/种子、计时与成本口径、得分、估算项、适用范围；“up to”不能补足缺项。只发现官方README继续重复旧数值不算条件补齐。2026-09-24来源仍有非浏览器基线名占位、单次与系列差别及估算成本；本轮无新完整证据时，公开新稿省略旧性能事实结论，审核记录缺口。不得把 Jev 数据推广给 Laya／Cua-S1 Nano、所有任务或每位用户；不得把文档核验说成实际基准复测。
- **SYS-F05｜历史、身份与发布状态。** Jev发布日期、模型发布顺序、社区反响、当前账号/公司身份、仓库“本周公开”等逐项核对。没有本次直接来源不写成当前事实；flat表达也不豁免日期和顺序核查。命令重命名须区别当前commit与正式release，未发布项不写成已稳定发布。预置场景名称不等于真实机器人或所有系统验证。链接指向原文不代表本轮新发了文章。

## 操作和保存边界

- **SYS-S01｜只继承方法。** 原件的产品运行命令、历史密钥位置、联系人、账号、DM、投稿、评论、排期、Git操作、DOCX制作、裁图和其他平台交付均不执行。本轮只整理/试写LinkedIn普通动态，既不发布也不保存为正式作品。读来源中的安装行只是读资料，不是安装授权。
- **SYS-S02｜证据不能冒名。** 审核不得声称已运行 ai-rhetoric-lint、出现 Total 分值、通过AI检测器、平台审核、作者批准、真实模型/工具接通或发布成功，除非各自有本次实际证据。一次文字审核不是平台认证；候选修订稿不是正式保存。保留初稿、审核、修订及未解决项，均仅 tmp，不在永久规则文档或执行日志复制用户稿件。

## 一次审核的输出约定

在同一次审核中逐项判定以下条目为 `pass`、`needs_revision`、`unresolved` 或 `not_applicable`。每个问题写规则ID、tmp稿件的可定位片段/段号、来源位置、为何违反、最小修订和未解决依据；不能仅写“AI味较重”“不够吸引人”或猜测传播效果。修订稿对应处理已有发现，不重新启动审核循环。

| 检查ID | 要检验的事实和表达 | 修订或保留动作 |
|---|---|---|
| `SYS-Q01` | 英文标题与固定值是否完全一致；中文译题是否仍为候选。 | 修复无授权的改写；中文确认状态只在审核/交付元数据中保留。 |
| `SYS-Q02` | model/agent/LLM术语与中英映射、示例名单是否稳定。 | 修复实际概念漂移，不以同义替换增加华丽程度。 |
| `SYS-Q03` | 所有产品/日期/性能/身份/完成状态主张是否有本次证据。 | 无依据则从新稿移除该事实结论或严格限定；记录缺口，不让作者语气盖过事实风险。 |
| `SYS-Q04` | caller/builder、System 1/LLM、单次/系列、Jev/其他模型是否混写。 | 拆开主体、动词和适用条件，保留关键边界。 |
| `SYS-Q05` | 缩写是否保持责任主体、否定、概率、条件、语气强度和独有信息。 | 只做最小必要编辑；不发明亲历、数据或因果，不为营销删除限制。 |
| `SYS-Q06` | 一条清楚用途是否贯穿正文，普通动态是否自足，链接是否真实。 | 补足理解所需上下文，删完整重复/占位符，不强塞长文大纲或CTA。 |
| `SYS-Q07` | 作者锁定表达、标签、选择的身份与本次风格是否冲突。 | 优先明确指示；将事实冲突独立列项，作者声音不能由评分替代。 |
| `SYS-Q08` | 三阶段执行、tmp边界、来源/实测/批准状态是否如实记录。 | 修正错误完成声明；保留待作者确认与证据不足状态，不将结果标成可直接发布。 |

上述检查不以总分、禁词命中率或审核次数充当质量结论。是否较旧规则改善，须看同输入试稿的具体事实和表达差异；本文件不提前宣称候选优于现有规则。
