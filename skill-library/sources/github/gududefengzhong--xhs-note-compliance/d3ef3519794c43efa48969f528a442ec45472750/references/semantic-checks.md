# 语义判定模板

词库和正则只能抓「写出来的词」，这份模板用于 Agent 判定「藏在意思里」的风险。
逐类过一遍，每类按模板自问，命中则按统一格式写进报告。

**输出格式（每条语义风险）**：

> - 【风险名】引用原句 → 为什么有风险 → 一句话改法

**数量上限**：语义层最多报 4 条，只挑最重要的。报告刷屏会稀释高风险项的分量。

---

## 一、隐性效果承诺

**定义**：不含违禁词，但通过归因、他人反应、前后对比暗示产品效果有保证。

**判定自问**：
1. 是否把身体/外貌/数据变化直接归因于某产品？（「一瓶下去斑点淡了」）
2. 是否借他人反应暗示效果？（「用完同事都问我是不是去做医美了」）
3. 是否有前后对比描述/对比图 + 归因于产品？
4. 是否暗示对所有人都有效？（「谁用谁知道」「无限回购就是答案」）

**正例（违规）**：「坚持用了一个月，同事都问我是不是偷偷去打水光针了」
**反例（安全）**：「我用了一个月感觉皮肤状态好了些，个人体验，因人而异」

**改法模板**：加「个人体验/因人而异」限定 + 去掉归因和他人反应 + 改为过程描述而非结果承诺。

## 二、疑似未报备商单

**定义**：实为商业合作但未声明、未走蒲公英报备的内容。**这类不是改词，是提醒报备。**

**判定**（结合脚本 JSON 输出里的 `signals` 字段），满足**任一组合**即报：

1. 价格信息 + 购买引导 + 无合作声明（signals 的 price / purchase_cta）
2. 单一品牌/产品提及 ≥ 4 次 + 通篇只有推崇没有缺点 + 无声明——内容营销特征，**不一定有价格信息**（例：「这款面膜我喜欢，朋友都在用」反复出现）
3. 返利/佣金/代理暗示（signals 的 affiliate_hint）——分销类商单信号，即使文内已声明合作，也要提醒确认走了蒲公英分销报备

**措辞**：「若本篇为合作内容，需走蒲公英平台报备并在文内声明，否则平台识别后可能被限流或处罚；若纯自来水分享，建议减少购买引导话术以免误判」。命中组合 3 时额外提醒：分销/返佣内容除常规报备外，还需符合平台分销规范——已声明合作 ≠ 已完成报备，两件事要分开确认。

## 三、站外导流变体

**定义**：绕过词库的创意导流写法。脚本已覆盖拼音（vx/wx）、空格、零宽字符，这里查更隐蔽的。

**判定自问**：
1. emoji 替代：「加我 v❤」「威❤」「➕我」
2. 拆字/分行：「威」和「信」拆在两行、竖排藏字
3. 谐音/同音生僻字：「喂心」「嶶信」「魏鑫」
4. 数字/字母混排的 ID 且上下文在引导联系：「找我 b8e8a8u8」
5. 图片里藏联系方式（读图时重点看角落、水印、贴纸文字）
6. 个人简介引导：「主页有惊喜」「看我置顶」配合站外信息

**原则**：只要读者能凭笔记内的信息拼图找到作者的站外联系方式，就是导流。
**改法**：一律删除，统一改为「欢迎站内私信」。

## 四、过度营销语气

**定义**：不违禁但「广告味」重，容易被判定为营销内容，可能影响推荐。

**判定自问**（结合脚本 JSON 的 `metrics` 字段）：
1. 感叹号密度：每 100 字超过 3 个？
2. 催促类话术连续出现？（快冲 / 别犹豫 / 听我的）
3. 通篇只有优点、没有任何缺点或适用限制？
4. 每段都在推进购买，没有真实使用场景细节？

**改法模板**：降低感叹号和催促密度 + 补真实细节（什么时候用、什么场景、用量）+
**主动写一个缺点或不适用人群**——这是去广告味最有效的一招，也更符合小红书真诚分享的社区调性。

## 与词库层的分工

| 层 | 负责 | 产出 |
|---|---|---|
| 脚本（词库+正则） | 写出来的违禁词、常见变体、商业信号、文风指标 | JSON 候选命中 |
| Agent 语义层（本模板） | 隐性承诺、报备判断、创意变体、语气 | 最多 4 条语义风险 |
| Agent 汇总 | 过滤误报 + 两层合并 | 核心改进清单 + 安全改写 |
