# 合规复核规则手册

供 Agent 在词库扫描之后做语义复核用。词库负责「词」，这份手册负责「意思」。

## 一、法规依据速查

| 依据 | 要点 | 对应词库分类 |
|---|---|---|
| 《广告法》第九条 | 禁止「国家级」「最高级」「最佳」等绝对化用语 | absolute / superlative |
| 《广告法》第十七条 | 非医疗/药品/器械广告不得涉及疾病治疗功能、不得使用医疗用语 | medical |
| 《广告法》第二十八条 | 虚假或引人误解的内容构成虚假广告（含虚构使用效果） | promise / effect_days |
| 《化妆品监督管理条例》 | 美白、祛斑、防晒、防脱等属特殊化妆品，需注册证才可宣称 | special_cert |
| 金融营销监管规定 | 不得承诺保本、保收益，不得夸大收益隐瞒风险 | finance |

## 二、小红书平台规则要点

1. **站外导流属高风险行为**：微信号、二维码、手机号、外链，包括一切变体写法。联系引导建议优先使用站内私信等平台内合规能力。
2. **商业内容需报备**：商单/软广要走蒲公英平台报备并声明合作。通篇夸单一产品、带购买引导却无声明的，按疑似未报备商单提示用户。
3. **诱导互动可能影响推荐**：点赞/关注/转发抽奖需走官方抽奖组件；「扣1」「求赞」类话术可能拉低内容质量评估。
4. **医疗健康内容需资质**：疾病诊疗、用药建议类内容仅限认证医疗账号发布，普通账号谈个人经历可以，给建议不行。
5. **真实分享优先**：虚构人设、摆拍冒充真实体验，被识别后可能影响整篇笔记的审核与推荐。

## 三、语义复核清单（词库扫不出来的）

> 逐类判定模板（自问清单、正反例、改法模板）见 `semantic-checks.md`，本节为速查概览。

逐项过一遍，命中则写进报告的「语义层风险」：

1. **隐性功效承诺**：不用违禁词但暗示效果——「用完同事都问我是不是去做医美了」「一瓶下去斑点肉眼可见变淡」。
2. **对比暗示**：前后对比图/对比描述 + 归因于产品 = 效果承诺。
3. **医疗建议**：推荐具体药品、剂量、疗程，或劝人停药/换药。
4. **收益暗示**：不说「稳赚」但晒收益截图 + 「跟着做就行」话术。
5. **导流变体**：emoji 替代（加我 v❤）、拆字（威 + 信分行）、谐音（喂心）、图片里藏联系方式。
6. **未报备商单特征**：单一品牌高密度出现 + 购买引导 + 无合作声明。
7. **引战表述**：地域、性别、职业对立；拉踩其他品牌（贬低竞品也是广告法禁区）。
8. **违规品类**：烟草（含电子烟）、处方药、医美机构引流、荐股带单——这些品类本身不可做种草内容。

## 四、常见误报与处理

| 命中 | 何时是误报 | 处理 |
|---|---|---|
| 最好 | 作副词表建议：「最好先试色」 | 剔除 |
| 第一名 / 第一 | 个人经历叙述：「跑了第一名」 | 剔除 |
| 治疗 | 就医经历分享：「去医院治疗了两周」 | 剔除，但检查是否顺带推荐了药品 |
| 微信 | 讨论微信产品本身的科技类笔记 | 剔除 |
| 防晒 | 泛谈防晒习惯而非宣称具体产品功效 | 降为提示 |

原则：**误报宁可剔除也不刷屏**——报告里全是误报会让用户不再信任高风险命中。

## 五、词库维护

- 词库在 `scripts/banned_words.json`，按分类组织，改完更新 `version` 字段。
- 平台规则随时在变：发现新的限流词（社区反馈、笔记申诉结果），加进对应分类；整类新风险则新建分类。
- 建议每月对照小红书社区公约和官方公告核一遍词库。
