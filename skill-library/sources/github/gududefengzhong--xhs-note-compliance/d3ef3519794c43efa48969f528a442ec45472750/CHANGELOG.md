# 更新日志

所有针对本项目的主要变更都记录在此。

版本号遵循 [Semantic Versioning](https://semver.org/) 规范：
- **主版本**（x.0.0）：词库或规则有重大改变，可能影响现有检查结果
- **次版本**（x.y.0）：新增规则、功能优化或大量词库补充
- **补丁版**（x.y.z）：修复误报、改进措辞、文档更新

## [2026-07] 初始版本

### [2.0.0] - 2026-07-03

> GitHub 开源首发版 | 双层检查 + 反馈机制

#### 🎉 新增

- ✨ **核心检查引擎**
  - 词库层：165 个分级风险词（高 127 / 中 22 / 低 16）、6 类正则模式、3 类商业信号
  - 语义层：隐性承诺、未报备商单、创意导流变体、过度营销语气
  - 自动复检：改写版会再次跑词库复检（最多 3 轮），两档口径——词库完全未命中标「已通过词库复检」，仅清除高风险项标「高风险项已清除，仍需确认中低风险」
  - Top 3 必改按类别优先级排序：站外导流/医疗功效/平台红线/金融承诺优先于普通绝对化用语，同类问题只占一个名额

- 📊 **商业信号识别**
  - 价格信息检测
  - 购买引导识别
  - 返利/佣金/代理暗示 ← **新增**（来自内部优化）

- 🏗️ **项目基础设施**
  - README.md：项目介绍、快速开始、常见问题
  - CONTRIBUTING.md：贡献指南和反馈模板
  - SKILL.md：Agent 使用说明（Agent Skills 格式，Claude Code / OpenClaw 等通用）
  - semantic-checks.md：语义判定模板

#### 🔧 改进

- 📈 语义判定逻辑升级
  - 未报备商单判定：从「三条同时成立」改为「任一组合即报」，覆盖面扩大
  - 返利/佣金识别：新增 affiliate_hint signal，覆盖分销类商单

- 📝 文档措辞优化
  - 图片处理说明：从「请用户誊录」改为「友好地说明一起检查」
  - signals 澄清：强调「不是违规项，只用于报备判断」
  - 改动对照表：新增改法原因说明

- 🖐️ 用户体验
  - 添加了反馈入口：用户可直接在 SKILL.md 末尾或 README 里看到如何提反馈
  - 月审流程说明：让用户知道反馈何时被处理
