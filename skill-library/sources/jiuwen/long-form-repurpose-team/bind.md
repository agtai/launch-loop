# bind.md — 资源限制、行为约束与降级模式

本文件是本团队反幻觉规则的**唯一真源**。`SKILL.md`、`workflow.md` 与全部 `roles/*.md` 均引用本文件，冲突时以本文件为准。

## Resource Constraints

| 项 | 值 | 说明 |
|---|---|---|
| `max_parallel_teammates` | 2 | Stage 1a 两个选段视角同时分派；Stage 1b 与 Stage 2 均为单角色顺序执行 |
| `total_wall_clock_budget` | 15 分钟 | 不含 Stage 0 的下载与 ASR 转写耗时（受源时长与硬件影响，不可控） |
| `total_token_budget` | 200k tokens | 转写全文会被送入 3 个角色，是主要消耗项 |
| 单次运行源文件数 | 1 | 不做批量。多个源请分多次运行 |
| 定稿切片数 | 由内容质量决定，硬上限 12 | 用户可通过 `{USER_CLIP_COUNT}` 指定；未指定时不设目标数，达标几段切几段 |
| 单角色转写输入上限 | 60000 字 | 超出时分块 |
| 源时长建议区间 | 30–120 分钟 | 短于 15 分钟通常无需拆条 |

**输入裁剪规则（性能关键）**：转写全文**只发给 Stage 1a 的两个选段角色**，它们需要在全篇里找段落。其余角色一律只收裁好的片段：

| 角色 | 收到的转写内容 |
|---|---|
| `info-density-scout` | 全文 |
| `emotion-peak-scout` | 全文 |
| `standalone-integrity-scout` | 候选段 + 前后各约 1000 字窗口 |
| `context-integrity-guard` | 每条切片原文 + 前后各约 500 字 |
| `platform-recomposer` | 不需要转写，只收定稿切片 |

把全文转发给下游角色会让总输入量翻数倍，而不提升判断质量——下游角色的工作都是对已选出的片段做裁决。

**输出裁剪规则**：`platform_matrix` 只覆盖 `{TARGET_PLATFORMS}` 指定的平台，未指定时默认三个（抖音、小红书、视频号）。每多一个平台就多一组标题、文案、话题标签，是本团队最大的输出开销。

**候选数量**：Stage 1a 两个角色只提交达到分数门槛的段落（信息密度 ≥ 50、情绪峰值 ≥ 60），各自上限为源时长每 5 分钟 1 条、不超过 12 条；用户指定 N 条时上限为 1.5N。上限只防止拖慢 Stage 1b，不是要凑满的目标。

**分块规则**：转写超过 60000 字时按章节或话题分块送入角色。分块边界**必须落在转写 segment 边界上**，不得从中间截断一个 segment，否则该处时间戳失效。每块携带前一块末尾 200 字作为衔接上下文并标注块序号，供 `standalone-integrity-scout` 判断跨块依赖。

**超预算处理**：`total_token_budget` 触顶时，优先减少进入 Stage 2 的切片数（保留共识数最高的），并在报告中说明，而非跳过角色。跳过任一 Stage 1 角色会使团队退化为单视角，失去核心价值。

## Behavioral Constraints

### 反幻觉硬约束（不可降级）

这六条不受任何降级级别、用户要求或时间压力影响。违反其中任何一条即为本技能的严重缺陷。

**约束 1．任何时间码必须可溯源到 L0 的 ASR 输出或 L1 的字幕文件。禁止基于内容推测生成时间码。**

若手上只有一段文字，你无法知道某句话出现在第几分钟。凭内容长度估算、按平均语速折算、参考"通常访谈的高潮在中后段"——这些全部属于推测，一律禁止。

**约束 2．在 L2 级别下，输出中不得出现任何 `HH:MM:SS` 格式字符串。**

包括正文、表格、代码块、ffmpeg 命令示例在内的任何位置。L2 下切片边界只能用原文引用表达（首句与末句原话）。

**约束 3．在 L3 级别下，不得产出切片方案。唯一合法输出是缺失项清单与补齐指引。**

用户催促、表示"你先大概给几个"、或提供了节目简介与话题列表，都不构成放宽本约束的理由。没有转写就是没有转写。

**约束 4．不得输出任何未经真实测量的音视频技术指标（响度、码率、分辨率、动态范围等）。**

本团队不提供音质与画质评估职能。若用户询问，如实说明该职能不在范围内。

**约束 5．输出示例必须标注为「示例数据，非真实测量结果」。**

避免示例中的时间码被误读为真实结果。

**约束 6．情绪判据必须溯源到真实韵律标记。**

`emotion-peak-scout` 的每条 `peak_evidence` 必须指向真实来源——segment 间隔秒数、语速相对基线的偏差、转写文本中的笑声标记、或 ffmpeg 音量分析结果。无 `{PROSODY_MARKERS}` 时置 `prosody_available: false`，且不得输出 `pause_tension` 或 `laughter` 类型的判定。禁止凭内容想象情绪起伏。

**约束 7．不得主动安装依赖。**

探测到工具缺失时，只报告缺失项与替代路径，**不得执行任何安装命令**。`openai-whisper` 体积超过 2GB（含 PyTorch 与模型权重），主动安装是替用户做重大决定。

缺 whisper 时的正确行为：告知用户可提供字幕文件走 L1（效果接近 L0），或提供文字稿走 L2。仅当用户明确要求安装时，才给出安装命令。

本约束优先于对 L0 精度的追求——降级运行远好于擅自改动用户环境。

**约束 8．只下载音频流，不下载视频流。**

Stage 0 的唯一目的是拿到带时间戳的转写，转写不需要画面。取源必须使用 `-f bestaudio`。

**本技能不产出视频文件。**报告中的 `ffmpeg` 切割命令是**交付给用户的可执行建议**，用于让用户自行验证时间码并切片——它不是本技能要执行的动作。不得为了"把切片切出来"而下载完整视频。

若用户已在本地拥有源视频文件，切割命令中的 `{SOURCE_FILE}` 指向该文件；若源来自链接且用户本地没有视频，在命令上方注明「需先自行下载源视频」，而不是替用户下载。

下载完整视频通常是音频体积的 10 倍以上，且对本技能的产出没有任何帮助。

**约束 9．默认用云端转写；只有退回本地转写时才需要先报耗时并等确认。**

1. **默认路径是运行 `scripts/transcribe.py`**：下载音频 → 压缩 → 在静音处分段 → 并行上传云端转写 → 拼回完整时间轴。它会自动使用 jiuwen 已配置的 OpenRouter / OpenAI key（模型 `whisper-1`），用户无需额外配置。一小时音频通常一两分钟完成，费用约 0.36 美元。
2. **不要为了省转写而四处寻找平台字幕**。云端转写已经足够快，找字幕反而容易撞上反爬、登录、硬字幕等问题，更慢更复杂。只有**用户主动提供**字幕文件时才走 L1。
3. 运行前在回复中告知用户音频时长与预计费用（脚本会打印），然后直接开始，无需等待确认。音频超过 3 小时（预计费用超过 1 美元）时，先等用户确认。
4. **云端转写不可用时**（脚本退出码 3），才考虑本地 whisper。此时必须先报告预计耗时并等用户确认，模型默认 `small`，不得默认 `medium`；实现按速度优先：`whisper.cpp` > `faster-whisper` > 官方 `openai-whisper`。
5. 不得用多模态对话模型（如 gpt-4o-audio）代替转写来获取时间码——对话模型给出的时间是生成的估计值，不可靠，违反约束 1。

本约束与约束 7（不得主动安装）不冲突：报告中可以**提及**安装某工具能快多少，但不得擅自安装。

**约束 10．不得绕过平台的访问限制。**

平台返回 412 / 403 等拒绝访问时（脚本退出码 4），不得伪造 cookie、伪装身份、换用其他域名或内部接口、反复重试等方式绕过反爬。

**正当的做法是使用用户本人浏览器的登录状态**，登录状态下的正常请求一般不会被拦截：

1. 询问用户一次：「平台拒绝了匿名访问，要用你浏览器里的登录状态下载吗？」用户同意后，加 `--cookies-from-browser chrome`（或用户使用的浏览器）重新运行转写脚本，无需用户自己下载任何文件。
2. 用户若希望以后不再询问，可在 jiuwen 配置 `.env` 中设置 `REPURPOSE_COOKIES_BROWSER=chrome`，脚本会自动使用，视为长期同意。
3. 用户不同意，或使用登录状态仍被拒绝时，再请用户提供本地音视频文件。

macOS 首次读取浏览器登录状态时会弹出钥匙串授权窗口，需用户点「允许」，应提前告知用户。

### 四级降级判定

按以下顺序确定，命中即停：

0. **用户主动提供了字幕文件**（`.srt` / `.vtt` / 平台导出的带时间戳转写）→ **L1**，直接解析，不再转写。
1. 用户提供了链接或本地音视频 → 运行 `scripts/transcribe.py` 走**云端转写** → **L0**。
   - 退出码 3（没有可用的云端转写服务）→ 进入第 2 步
   - 退出码 4（平台拒绝访问）→ 按约束 10 征得用户同意后用其浏览器登录状态重试（`--cookies-from-browser`）；不同意或仍失败再请用户提供本地文件
2. 本地有 ASR 实现（`whisper.cpp` / `faster-whisper` / `whisper`）→ **先报告预计耗时并等用户确认**，确认后走本地转写 → **L0**
3. 以上都不行，询问是否有无时间戳的文字稿 → 有则 **L2**
4. 以上均无 → **L3**，停止执行

**每一步的结果都必须如实告知用户**：用的是哪种转写、花了多少钱或多久、降到了哪一级、该级别下会损失什么。不得静默降级。

缺少工具时只**告知**，不安装（约束 7）：

| 缺失工具 | 影响 | 用户可选的安装命令 |
|---|---|---|
| `ffmpeg` | 无法处理音频，云端与本地转写都无法进行 | macOS `brew install ffmpeg` / Linux `sudo apt install -y ffmpeg` |
| `yt-dlp` | 无法从链接下载，需用户提供本地文件 | macOS `brew install yt-dlp` / Linux `pip install -U yt-dlp` |
| 云端转写 key | 退回本地转写（慢） | 在 jiuwen 中配置 OpenRouter 或 OpenAI 模型即可；或设置环境变量 `ASR_API_BASE` / `ASR_API_KEY` / `ASR_MODEL` |

判断依据是**实际运行环境**，不是用户本机——本技能可能运行在云端平台上。

| 级别 | 触发条件 | 行为 | 产出 |
|---|---|---|---|
| **L0 全自动** | 链接或音视频文件 + 可用的转写（云端优先） | 下载音频 → 转写 | 真实句级时间戳转写 + 韵律标记 |
| **L1 字幕** | 用户提供 `.srt` / `.vtt` / 平台导出转写 | 解析字幕文件，跳过转写 | 真实句级时间戳 |
| **L2 降级** | 仅有无时间戳文字稿 | 正常选段，但不输出任何时间码 | 内容边界描述（引用原文首尾句）+ 显式标注「无时间码，需人工定位」 |
| **L3 拒绝** | 以上均无 | 停止执行，明确告知缺什么、如何补 | 不猜、不编、不输出任何时间码或时长估计 |

### 各级别能力差异

| 能力 | L0 | L1 | L2 | L3 |
|---|:--:|:--:|:--:|:--:|
| 精确时间码 | 有 | 有 | 无 | 无 |
| ffmpeg 切割命令 | 有 | 仅当用户提供了源文件 | 无 | 无 |
| 停顿 / 语速韵律判据 | 有 | 有 | 无 | 无 |
| 音量突变判据 | 无（当前脚本未实现） | 无 | 无 | 无 |
| 选段与钩子改写 | 有 | 有 | 有 | 无 |
| 断章取义审查 | 有 | 有 | 有 | 无 |

### 角色隔离约束

- `info-density-scout` 与 `emotion-peak-scout` 必须并行分派且**互相不可见**。把任一方的输出传给另一方会导致视角收敛，团队价值崩塌。
- `standalone-integrity-scout` 只接收候选段的**边界与原文**，不接收前两者的评分与理由。
- `context-integrity-guard` 必须在 `platform-recomposer` 之后分派，且不得由同一角色兼任——创作与风险审查合并会导致自我审查失效。

## Failure Handling

| 失败场景 | 处理 |
|---|---|
| ASR 转写失败（模型加载失败、音频损坏） | 降至 L1，告知失败原因，请求字幕文件。不得用文件名或简介编造内容 |
| 字幕文件解析失败（编码错误、格式非法） | 报告具体行号与该行原始内容，请用户确认。不猜测被破坏的时间戳 |
| 源文件下载失败 | 报告 HTTP 状态码或 yt-dlp 原始错误。不虚构时长、标题或内容 |
| 音轨抽取失败（源无音轨） | 停止并告知：本技能依赖语音内容，无声源无法处理 |
| Stage 1 某角色输出不符合 Output Schema | Leader 重新分派该角色一次；仍失败则在 Final Report 中标注该视角缺失。**不得由 Leader 代写该角色的结论** |
| Stage 1 两个选段角色全部失败 | 停止，报告失败，不产出切片方案 |
| `standalone-integrity-scout` 失败 | 可继续，但全部切片标注为「未经独立性审查」，建议人工复核脱离上下文的风险 |
| `platform-recomposer` 失败 | 降级输出：仅给定稿时间码与 `core_claim`，不给钩子与封面，明确标注缺失 |
| `context-integrity-guard` 失败 | **不可降级**。守卫是风险闸门，缺失时全部切片标注为「未经风险审查」，并建议人工复核后再发布 |
| 转写语言与目标平台语言不一致 | 如实指出，询问是否需要翻译。本技能不做字幕翻译 |
| 触及 `total_token_budget` | 减少进入 Stage 2 的切片数并说明，不跳过角色 |

### 降级模式（degraded mode）

依赖缺失导致无法进入 L0 时，团队仍可在 L1/L2 下完整运行全部五个角色。降级影响的是**素材层的精度**，不是**多视角评审的完整性**。

唯一会导致团队无法运行的情况是 L3——此时没有任何可供角色分析的文本。
