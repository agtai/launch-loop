# 执行护栏

## 资源限制

| 条目 | 限制 | 原因 |
|---|---|---|
| `max_parallel_teammates` | 3 | 对应 3 角色并行展开 |
| `total_wall_clock_budget` | 8 分钟 | 预检 + 3 个并行角色 + 整合 |
| `total_token_budget` | 100k tokens | 视觉简报较短；3 × 约 25k + 整合 |
| `per_role_token_budget` | 25k tokens | 对称——每个角色范围有限 |

## 行为约束

- **Leader 仅作编排者**：Leader 收集简报并整合输出。Leader 不设计视觉概念，不撰写无障碍文案。
- **角色隔离**：各角色在工作期间不得看到彼此的输出——platform-adapter 在形成独立规格之前，不得受到 visual-concept-designer 概念的影响。
- **冲突呈现**：当视觉概念与无障碍要求或平台规格发生冲突时，Leader 逐字呈现双方立场。Leader 绝不解决设计冲突。
- **不做实际制作**：本团队仅生成创意简报。不生成图像、不创建设计稿、不制作实际视觉素材。

## 失败处理

### (a) 队友失败

| 失败模式 | 应对 |
|---|---|
| 队友超时 | 重试一次。第 2 次超时时，将该角色部分标注为 `[MISSING]` 并继续。 |
| 平台适配者遗漏某个平台 | 重新派发并加入"您遗漏了 [平台]"指令。最多重试 1 次。 |
| 输出格式不符 | 重新派发并内联 Output Schema。最多重试 1 次。 |

### (b) 输入超量降级

| 触发条件 | 降级模式 |
|---|---|
| 目标平台 > 5 个 | 请用户优先选择前 3 个；其余平台注明"参照最接近的格式进行适配" |
| 未提供品牌规范 | 在无品牌约束的情况下继续；标注"制作前需进行品牌审核" |
| 各平台风格要求相互冲突 | 向用户呈现冲突；不尝试解决 |

### 升级规则
- 如果 2 个及以上角色返回 `[MISSING]`，输出带 `FAILED: insufficient coverage` 标签的部分简报。
- 如果超过 `total_wall_clock_budget`，输出带 `INCOMPLETE: budget exceeded` 标签的部分简报。
