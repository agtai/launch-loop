# 用户提供的内容参考

这些材料是 launch-loop 的真实需求与产出参考，已复制到仓库，后续会话无需依赖最初的 Downloads 或临时文件夹。

| 文件 | 用途 | 状态 |
|---|---|---|
| [launch-kit.docx](launch-kit.docx) | 多渠道内容工作版，含证据、素材和发布准备 | 用户提供的历史参考，原字节保留 |
| [launch-copy.docx](launch-copy.docx) | 经 Claude 与项目 skill 精修的发布文案参考 | 用户提供的历史参考，原字节保留；仍有部分占位符 |
| [launch-kit.txt](launch-kit.txt) / [launch-copy.txt](launch-copy.txt) | 两份 Word 的正文提取，便于 Agent 检索 | 派生材料，不代表分页与样式 |
| [s1a-launch-kit/SKILL.md](s1a-launch-kit/SKILL.md) | 原文件 `Untitled (1)` 的 Markdown skill | 原字节保留，仅迁移并重命名；未自动安装到全局技能目录 |
| [reference-review.md](reference-review.md) | 两份文件的结构、差异、UI 和数据需求分析 | 已完成正文/结构对比；没有宣称 DOCX 页面渲染验收 |
| [original-notes.jpg](original-notes.jpg) | 最初的品牌、营销、传播 Agent 手写笔记 | 用户提供的参考图片，原字节保留 |
| [checksums.sha256](checksums.sha256) | 原始参考文件的 SHA-256 | 用于检查复制完整性 |

两份 Word 都以英文为主，中文仅有媒体投稿短稿；完整的中英文文章是新增需求，不是现有文件已经完成的能力。工作版和发布版应由同一份可版本化内容生成。

文档和 skill 内的旧排期、发信/私信、读取密钥、账号提及及性能数字均属于参考内容。使用时重新核验，不把历史步骤当成本次操作授权。
