## 本机文本真实调用

没有读取 `auth.json`、token、历史凭据或环境变量值，也没有登录新账户或购买服务。由 CLI 自己使用已有登录；官方文档确认 [CLI 支持 ChatGPT 登录](https://learn.chatgpt.com/docs/auth)，[非交互执行](https://learn.chatgpt.com/docs/non-interactive-mode)可复用 CLI 登录、输出 JSONL，并以 `--ephemeral` 避免持久化会话 rollout。

首试等效调用（在仓库根目录运行，正文不进入文档）：

```powershell
codex --no-daemon -a never exec --ignore-user-config --ephemeral --skip-git-repo-check -C tmp/preflight -s read-only -m gpt-6-astra -c 'model_reasoning_effort="high"' -c project_doc_max_bytes=0 --json -o tmp/preflight/codex-text.txt '<最小双语生成请求>'
```

请求仅让模型生成一句中文和一句英文的本地写作工作台介绍，明确不调用工具、不读写文件、不联网检索、不委派；内容只包含可修改草稿、保存须经作者确认。用 `gpt-6-astra`／High 与本轮模型要求保持一致；正文不涉及用户真实产品或私人素材。

- 首轮开始约 14:07:40、完成 14:09:40（Europe/Paris），外层命令 exit 0。
- 产出 199 字节，合法 JSON，字段 `zh`／`en`；对应字符串长度 27／101。SHA-256：`3467B5096D57CCAEDD0E7DDEEDB1869804506AFF1E175E7578AFD4F75058E20F`。
- 首试结果副本：[tmp/preflight/codex-first-result.json](../tmp/preflight/codex-first-result.json)；未确认正文：[tmp/preflight/codex-first-text.txt](../tmp/preflight/codex-first-text.txt)。这些为本地临时证据，Git 不收录，不作为正式内容库。

## LinkedIn：普通动态与原生长文

[Share on LinkedIn](https://learn.microsoft.com/en-us/linkedin/consumer/integrations/self-serve/share-on-linkedin) 明确：应用添加 Share on LinkedIn 产品以取得 `w_member_social`，用户通过 OAuth 授权后得到访问 token。已有 LinkedIn 网页登录不等于本工作台获得这些权限；本文未检查用户开发者后台。

[Posts API](https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/posts-api?view=li-lms-2026-09) 的个人动态权限为 `w_member_social`；组织动态另需 `w_organization_social` 与相应页面角色。请求为 `POST /rest/posts`，需要 bearer token、`Linkedin-Version` 与 `X-Restli-Protocol-Version`；正文用 `commentary`，作者使用对应 URN。实际接入仍需检查应用获准产品和接口版本，不将旧 Share 指南的 `/v2/ugcPosts` 示例与新 Posts API 任意混用。本文只读取公开页面，没有发送任何带凭据 API 请求。

同一文档的 `content.article` 示例是 `source`、`thumbnail`、`title`、`description`，没有原生长文正文输入。**原生 Pulse 正文自动创建仍未证实**；状态应与普通动态“接口存在但未连接”分开。保存稿件或生成发布包不等于线上发布；发布须绑定另一次明确授权、具体已确认版本、渠道、账户及实际返回结果。详细背景见 [LinkedIn 发布与反馈接入核查](LinkedIn发布与反馈接入核查.md)。反馈分析本轮不继续设计或测试。
