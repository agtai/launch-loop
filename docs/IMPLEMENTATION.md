# 本地内容工作台实现计划

目的：沿用已有五步内容流程，交付单人本地、无需平台登录的可编辑工作台，并补齐品牌管理/营销创业产品竞品研究与每项工作的复用说明。

架构：React 页面编译为静态文件；Node 内置 HTTP 与 SQLite 在 127.0.0.1 运行；数据库存入 data/，不再依赖 Sites、D1 或 ChatGPT 身份验证。保留原云端项目，另建独立本地目录。

执行授权：用户已明确要求实现本地工作台及补齐调研；沿用前序已提出的一键启动、明确保存、备份方案，不再增加设计审批。

- [x] 本地存储接口：模块和任务分别版本控制；写入冲突不覆盖，备份恢复先验证后事务提交。
- [x] 本地页面：五模块、详细任务清单、可检索复用库、产品横向对照、使用及分工架构。
- [x] 调研：核准 Frontify / Frontity；品牌工具与营销 agent 创业产品分别调查；原始链接、核查日期、证据级别完整。
- [x] 操作资料：每项任务的输入、步骤、交付物、验收、依赖、复用对象/方法/理由；实际资料试跑与未测试项目分开。
- [x] 交付：Windows 一键启动和停止；HTML/CSS/JS 预构建；数据库备份导出/导入；说明与可交接 Markdown。
- [x] 验证：保存重启保留、并发冲突、备份恢复、来源与路径限制、浏览器交互和移动布局、独立复核。

重点风险：来源缺失或过期、把供应商文档当试用、把调研完成当实际发布、恢复备份覆盖新状态、非技术用户启动失败。逐项验证并写入测试记录。
