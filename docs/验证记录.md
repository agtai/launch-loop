## 修正与未覆盖范围

本次修正了完整备份可能超过恢复接口容量、失效进程记录阻止重新启动、关闭编辑器直接丢弃修改，以及冲突后缺少保留草稿并读取最新版本入口的问题。恢复上限现为 16 MiB；普通写入仍为 2 MiB。

“下载草稿并载入最新版本”入口已实现并通过构建；并发冲突由后端自动测试验证。本次未逐个做所有浏览器版本与系统版本的兼容测试。便携包适用 Windows x64，不宣称已在 macOS、Linux 或 Windows ARM 上验证。

供应商研究仅核验官方资料，没有登录商业产品试用或连接社媒账号。资料与文案样例为未发布草稿，没有把平台曝光、真实反馈或产品基准执行列为已完成。

本地工作台是可持久化的运营台账、方法库与交接入口；目前不自动调用模型、不自动发布、不抓取评论，也不提供多台电脑实时协同。
